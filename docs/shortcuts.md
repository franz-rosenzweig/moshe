# Keyboard shortcuts

This page lists every key Moshe knows. They're the usual keys of a Mac writing app, so your hands may already know most of these, and they work the same in a browser, in the Mac app and on Android with a keyboard. Outside the Mac, **Ctrl** takes the place of **⌘**, and the few keys with both **⌃** and **⌘** are for the Mac.

## The window

| Key | What it does |
|---|---|
| **⌘1** | Show the library, the sheet list and the editor |
| **⌘2** | Show the sheet list and the editor (again: all three) |
| **⌘3** | Show only the editor (again: all three) |
| **⌘4** | Show or hide the dashboard |
| **⌘.** | Focus mode: only the page, the bars back when you go up to them (again: everything back) |
| **⌃⌘F** | Full screen |
| **⌥⌘3** | Open or close the second editor |
| **⌥⌘←** / **⌥⌘→** | Move between the two editors |
| **⇧⌘T** | Translation mode |
| **⇧⌘E** | Revision mode |
| **⌘6** | Export |
| **⌘7** | The dashboard's Progress view |
| **⌘8** | The dashboard's Outline view |
| **⌘+** / **⌘−** / **⌘0** | Bigger text, smaller text, the usual size |
| **⌘,** | Settings |
| **Esc** | Close a menu, Open Quickly or Settings |

## The library and the sheets

| Key | What it does |
|---|---|
| **⌘N** | New sheet, in the selected group (or the Inbox) |
| **⌃⌥⌘N** | New material sheet |
| **⇧⌘N** | New group |
| **⌃⌘N** | New filter |
| **⇧⌘I** | Import |
| **⌘O** or **⇧⌘F** | Open Quickly: find a sheet, a group or a project |
| **⌘[** / **⌘]** | Back and forward through the sheets you've opened |
| **⌥⌘↑** / **⌥⌘↓** | The sheet above or below in the list |
| **⌃⌘↑** / **⌃⌘↓** | Move the selected sheets up or down (in a group sorted manually) |
| **⌘D** | Duplicate the sheet (outside the editor) |
| **⌃⌘U** | Add to Favorites, or remove |
| **⇧⌘U** | Show the Favorites |
| **⌃⌘M** | Mark as Material, or as text again |
| **⇧⌘K** | Keywords |
| **⇧⌘P** | Export |
| **⌘⌫** | Move the selected sheets to the Trash (in the sheet list) |

In the sheet list, **↑** and **↓** open the sheet above or below, **Shift-↑** and **Shift-↓** select a run of sheets (to glue or merge them), **Return** or **→** goes into the text, and **←** goes back to the library.

## Writing

| Key | What it does |
|---|---|
| **⌘B** | Strong |
| **⌘I** | Emphasis |
| **⇧⌘H** | Mark (highlight) |
| **⇧⌘C** | Comment |
| **⇧⌘D** | Delete (marked, not cut) |
| **⌘K** | Link |
| **⌥⌘1** / **⌥⌘2** | Title, heading |
| **⌥⌘4**, **⌥⌘5**, **⌥⌘6** | Smaller headings |
| **⌥⌘0** | Back to a plain paragraph |
| **⌥⌘8** | Dashed list |
| **⌥⌘7** | Numbered list |
| **⌥⌘Q** | Quote |
| **⌘L** | Clear the markup from the selection |
| **⌘9** | The markup menu, at the cursor |
| **⇧⌘B** | Split the sheet at the cursor |
| **⇧↩** | A new line, without continuing a list |
| **⌃⌘↑** / **⌃⌘↓** | Move the line up or down |
| **Tab** / **⇧Tab** | Indent and outdent a list, move between table cells |
| **⌥⇧⌘V** | Paste as plain text |
| **⌘Z** / **⇧⌘Z** | Undo, redo |

## Finding

| Key | What it does |
|---|---|
| **⌘F** | Find in the sheet |
| **⌥⌘F** | Find and replace |
| **⌘G** / **⇧⌘G** | Next and previous match |
| **⌘E** | Use the selection to find |
| **⌘O** or **⇧⌘F** | Search the whole library |

## Only in the Mac app

| Key | What it does |
|---|---|
| **⌥⌘N** | A new window on the same library |
| **⌘W** | Close the window |
| **⌘P** | Print |
| **⌘M** | Minimize |
| **⌃⌘Z** | Zoom the window |

The Mac app's menu bar has every item, with the same keys, and an item Moshe doesn't have yet shows greyed out. The whole list, menu by menu, is in [MENUS.md](MENUS.md).
